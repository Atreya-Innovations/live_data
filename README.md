# Atreya Innovations — Nadi Tarangini India Device Intelligence Map

> **Live Production Dashboard:** [livedatant.vercel.app](https://livedatant.vercel.app/)

A real-time React visualization dashboard displaying pulse diagnostic readings from Nadi Tarangini devices across India. Features a continuous Inverse Distance Weighted (IDW) weather-style heatmap engine rendered on an HTML5 canvas and clipped strictly to Indian state boundaries.
